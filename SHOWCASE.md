**Project creator:** Sameer Shrivastava

**Repository:** https://github.com/sshrivastava800-web/airmouse-lab

## Project summary

An experimental, offline webcam mouse that translates hand landmarks into cursor movement, pinch clicks and scrolling. Includes adaptive smoothing, a safety lock, optional dwell-clicking, and automated tests.

**Skills:** Python · OpenCV · Computer Vision · MediaPipe · Human–Computer Interaction · Unit Testing

## Demo checklist

- Test on a Windows computer with a working webcam before describing the project as hardware-tested.
- Record the webcam preview while moving the cursor using the index finger.
- Demonstrate left/right pinch clicks and two-finger scrolling in a harmless test window.
- Show the safety pause gesture and optional dwell-click progress ring.
- Hide personal notifications and other sensitive screen content during recording.
